## Om projektet

Et fuldt funktionelt multiplayer skakspil, hvor to spillere kan spille mod hinanden fra hver sin computer via en direkte TCP-forbindelse. Alle officielle skakregler er implementeret, og spillet synkroniserer automatisk brættets tilstand mellem de to spillere i realtid.

### Installation

```bash
git clone https://github.com/hamz0640/Multiplayer-Chess-Game-
```

Åbn `.sln`-filen i Visual Studio, byg projektet med `Ctrl+Shift+B`, og kør med `F5`.

### Netværk

**Host (hvide brikker):** Klik **Host Game** og del din IP-adresse med modspilleren.  
**Klient (sorte brikker):** Indtast værtens IP og klik **Join Game**.

> Begge spillere skal være på samme netværk, eller vært skal have åbnet **port 2026 (TCP)** i sin router.
